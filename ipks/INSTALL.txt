Hiveton H5000M（OpenWrt 25.12 / aarch64_cortex-a53）ipk 安裝套件
==================================================================

【主要套件（最終版）】
  luci-app-qmodem-next_3.4.0_rc3-r53   CPE 管理介面（儀表板/網路拓撲/AT 指令/APN 設定檔/簡訊/繁體中文）
  luci-i18n-qmodem-next-zh-tw          CPE 介面繁體中文翻譯
  luci-i18n-qmodem-next-zh-cn          CPE 介面簡體中文翻譯

【qmodem 核心與附屬套件】
  qmodem、libqmodem-sms、qmodem-smsd、modem_scan、ubus-at-daemon、
  qmodem-settings、qmodem-seal、sms-forwarder-next、sms-tool_q、
  tom_modem、quectel-CM-5G-M、ndisc6

【系統相依套件】
  bc、curl、libcurl4、jq、libsqlite3-0、ucode、ucode-mod-ubus、ucode-mod-uci、
  coreutils、coreutils-sort、coreutils-stat、flock、xxd、usbutils、usbids、
  pciids、ca-bundle、libmbedtls21、libsodium、libnghttp2-14、libncurses6、
  terminfo、zlib

【安裝方式】
  1. 上傳整個目錄到路由器：
       scp -r ipks root@192.168.50.254:/tmp/
  2. 在路由器上一次安裝（opkg 會自動處理相依順序）：
       cd /tmp/ipks && opkg install *.ipk
     ※ 翻譯套件版本號未變動時不會更新，請加 --force-reinstall：
       opkg --force-reinstall install luci-i18n-*-zh-tw_*.ipk
  3. 安裝後瀏覽器以 Ctrl+F5 重新整理 LuCI 頁面。

【備註】
  - 本目錄僅保留最新且運作正常的版本；舊版與出問題的版本已移除。
  - 已裝過舊版 ipk 的機器直接覆蓋安裝即可，設定值保留。
  - 風扇溫控（luci-app-fan-ctrl）與獨立網路拓撲（luci-app-net-topology）
    不在本目錄與本 repo 範圍內。
